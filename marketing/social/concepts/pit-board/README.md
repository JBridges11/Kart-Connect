# Pit Board (concept, not yet approved)

Punchy single-image posts inspired by the owner's Motorsport Connector reference. Dark and light tiles alternate,
so with 3 columns the Instagram grid reads as a chequered flag. Faded Kart Connect mark in the background,
chequered strip on every tile, Barlow Condensed Black Italic for headlines (outline + solid), Inter for body.

Build: copy logo.png, logo-white.png and the screenshots next to gen.py, run `python3 gen.py`, then
`node ../../render.cjs pit.html out`.
